# Gorillaz - The Mountain

[Gorillaz -The Mountain ft. Dennis Hopper, Ajay Prasanna, Anoushka Shankar, Amaan & Ayaan Ali Bangash](https://youtu.be/a2IdAW2A1ug?si=ESMKC07APd6FcPqz)

## Requirements

- [LilyPond](https://lilypond.org/)

### Optional

- [Frescobaldi](https://www.frescobaldi.org/)
  - Requires: `fluidsynth -a pulseaudio -m alsa_seq /usr/share/sounds/sf2/FluidR3_GM.sf2`

## Build

Run

```shell
lilypond gorillaz-mountain.ly
```

This creates:

- gorillaz-mountain.midi
- gorillaz-mountain.pdf
